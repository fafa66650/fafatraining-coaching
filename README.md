# FAFATRAINING COACH STUDIO

V94 FINAL CLEAN construite sur la base fonctionnelle verrouillée V93, avec migration automatique des données locales antérieures.

Principales évolutions : timer avec validation explicite et presets, accueil sans doublons, visuels univers non coupés, bibliothèque mouvements multi-tags, repères RIR/RPE expliqués, 120 programmes équilibrés (15 par univers) et filtres Sans matériel / Petit matériel / Salle-spécifique.

Déploiement GitHub Pages : envoyer le contenu de ce dossier à la racine du dépôt. `index.html` doit rester à la racine.
