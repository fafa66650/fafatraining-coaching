# FAFATRAINING V79 — INTUITIVE COACH OS

Projet web/PWA statique prêt pour **GitHub Pages**.

## Ce qui change réellement
- onboarding en 7 écrans simples au lieu d'un formulaire dense ;
- accueil avec une seule action principale : créer une séance ;
- création en 3 décisions : objectif, durée, état du jour ;
- profil, niveau, matériel et objectifs mémorisés ;
- adaptation par fatigue, stress, sommeil, douleur, âge, niveau et zones à protéger ;
- moteur différent selon musculation, boxe, HIIT, cardio, trail, Cross training, Hyrox, aérobic, mobilité, prévention, récupération ;
- bibliothèque : **424 exercices uniques** avec variantes, consignes, erreurs, muscles et matériel ;
- remplacement d'un exercice directement dans la séance ;
- mode séance en direct : séries, répétitions, poids, RPE ;
- historique, volume, temps et 1RM estimé ;
- gestion de plusieurs profils/adhérents ;
- export/import JSON ;
- impression/PDF ;
- PWA et cache hors ligne ;
- visuels FAFATRAINING intégrés selon le type d'entraînement.

## Mise en ligne GitHub Pages
1. Décompresser le ZIP.
2. Copier **tout le contenu** à la racine du dépôt `fafatraining-coaching`.
3. Commit + Push.
4. GitHub > Settings > Pages > Deploy from branch > `main` / root.
5. Ouvrir le site avec `?v=79` la première fois si le navigateur garde une ancienne version.

Aucun build npm n'est nécessaire.
