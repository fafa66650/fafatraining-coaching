# FAFATRAINING Coach Studio — V100 CLEAN CORE

Nouvelle base propre, reconstruite autour d’un seul runtime V100 pour GitHub Pages, iOS, Android et ordinateur.

## Contenu
- 1 509 mouvements techniques uniques, recherchables par univers, zone, muscle, matériel et méthode.
- 600 programmes FAFATRAINING prêts à utiliser, tous structurés avec prescriptions détaillées.
- 3 adaptations internes par programme : Accessible, Standard, Intensif.
- Programmes complets : séries, répétitions/durée, récupération, tempo/rythme, intensité, consignes et FAFA TIPS.
- Planning Coach, écran Aujourd’hui, cycles, Séance Express et Mode Séance en direct.
- Adhérents, mensurations, performances, historique, recherche globale et sauvegarde/import JSON.
- Studio Social : carrousel Instagram, Story/TikTok, Reel Cover et fiche adhérent.
- Timer Coach, remplacement intelligent, FAFA TIPS, variantes et mouvements personnalisés.

## Base technique nettoyée
- Aucun ancien fichier runtime de version précédente dans le package.
- Schéma programmes V100 unifié : `bodyZone`, `frequency`, `variants`.
- Une seule paire CSS/JS V100 et un seul Service Worker V100 CLEAN.
- Les données locales utilisent une clé neutre `fafatraining_coach` ; les sauvegardes JSON restent importables.

## Déploiement GitHub Pages
Copier tout le contenu du ZIP à la racine du dépôt. `index.html` doit rester à la racine.


## Navigation V100
Dock principal : Accueil · Adhérents · Créer · Programmes · Mouvements. Les Cycles / programmation restent accessibles depuis Programmes et les raccourcis Coach.
