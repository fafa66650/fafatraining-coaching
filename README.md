# FAFATRAINING V80 — COMPLETE INTUITIVE COACH OS

Version complète prête pour GitHub Pages. V80 reprend V79 mais refond la création de séance et l’adaptation du jour pour éviter l’effet « formulaire technique ».

## UX
- onboarding guidé en 7 étapes ;
- accueil avec action principale évidente ;
- création en 4 écrans : univers → style précis + durée → état du jour → résumé ;
- styles spécifiques par discipline : Push/Pull/Haut/Bas, Tabata, 40/20, EMOM, AMRAP, For Time, boxe technique/sac/puissance/appuis, trail côtes/fractionné/technique, Hyrox ergos/carries/simulation, etc. ;
- adaptation d’une séance déjà créée : plus courte, plus facile, plus intense, moins de matériel, sans saut, séance différente ;
- remplacement exercice par exercice ;
- fiches exercices détaillées ;
- interface responsive et PWA.

## Moteur coach
- âge, niveau, objectif principal/secondaire ;
- matériel et lieu ;
- fatigue, stress, sommeil et douleur du jour ;
- zones à protéger ;
- historique anti-répétition ;
- adaptation jeunesse/senior ;
- prescriptions séries/reps/temps/distance/rounds/repos/tempo/RPE ;
- suggestion de charge uniquement si un historique de charge existe ;
- sinon consigne RPE, sans poids inventé.

## Contenu
- 423 exercices uniques ;
- 15 univers sportifs ;
- variantes, muscles, matériel, niveau, consigne, erreur fréquente ;
- Boxe, Musculation, Force, Full Body, HIIT, Cardio, Trail, Cross training, Hyrox, Aérobic, Mobilité, Prévention, Récupération, Perte de poids, Remise en forme.

## Suivi
- multi-profils / adhérents ;
- séance en direct ;
- séries, répétitions, charge et RPE ;
- minuteur repos ;
- historique ;
- volume total ;
- 1RM estimé ;
- export/import JSON ;
- impression/PDF.

## GitHub Pages
Décompresse le ZIP et copie tout son contenu à la racine du dépôt `fafatraining-coaching`. Aucun build npm n’est nécessaire.

Après déploiement, ouvre une fois le site avec `?v=80` si Safari garde l’ancienne version en cache.
