# FAFATRAINING COACHING V30 — Ultra Clean

FAFATRAINING COACHING est une application pensée pour les coachs, éducateurs sportifs et pratiquants qui veulent créer une séance claire, rapide et adaptée.

Elle sert à :
- préparer une séance selon le niveau, l’objectif, le temps disponible et le matériel ;
- adapter automatiquement en cas de fatigue ou de blessure ;
- guider le client exercice par exercice avec chrono, séries et consignes simples ;
- exporter une séance en PDF A4 ou en carré type visuel programme ;
- garder une bibliothèque propre, sans doublons inutiles.

## Ambiance

Simple. Lisible. Terrain.  
Un outil qui va droit au but : tu choisis le profil, tu lances la séance, tu suis, tu exportes.

## Dossiers visuels

Les illustrations de mouvement sont rangées ici :

- `assets/photos/` : photos réalistes par mouvement
- `assets/avatar/` : avatar FAFATRAINING en posture d’exercice
- `assets/mix/auto/` : visuels fusion photo + avatar
- `assets/fallback/` : visuel de secours

Le fichier `VISUELS_A_CREER.csv` te donne le nom exact de chaque visuel à créer.

## Déploiement GitHub

1. Dézipper.
2. Envoyer tout le contenu à la racine du dépôt GitHub.
3. Activer GitHub Pages : branche `main`, dossier `/root`.
4. Ouvrir l’URL.

## Exports

- PDF A4 : bouton `Exporter PDF A4`
- Carré Insta : onglet `Suivi` puis `Exporter carré Insta`
