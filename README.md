# FAFATRAINING — COACH FLOW 


## Principe UX
L’application est maintenant organisée selon le travail réel du coach :

**Accueil → Coaché → Créer → Séance → Partager / Suivre**

La page d’accueil ne contient plus le catalogue complet des sports et n’affiche plus le prénom d’un adhérent dans son titre.

## Navigation principale
- Accueil
- Coachés
- Créer
- Bibliothèque
- Suivi

Les réglages sont placés en haut à droite. Les pages secondaires ont une petite pastille **Retour**.

## Coachés
- listing complet ;
- création et modification ;
- suppression ;
- profil sportif ;
- historique individuel ;
- création directe d’une séance ;
- partage d’une séance par le partage natif du téléphone ou copie du programme.

## Création de séance
Parcours chronologique en 4 étapes :
1. Pour qui ?
2. Objectif + style précis
3. Contexte du jour
4. Validation

Le profil mémorise les données permanentes. On ne redemande que ce qui change aujourd’hui.

## Bibliothèque restructurée
- 161 fiches **mouvements maîtres** ;
- 423 variantes réelles derrière ces fiches ;
- une fiche Squat / Pompes / Rowing / Boxe technique, etc. peut regrouper plusieurs variantes ;
- niveaux Débutant / Intermédiaire / Avancé / Expert dans la même fiche ;
- matériel, muscles, consigne correcte et erreur à éviter ;
- recherche + discipline + niveau + matériel ;
- un seul bouton **Effacer les filtres** : suppression des pastilles redondantes.

## Séances
- échauffement ;
- préparation spécifique ;
- bloc principal ;
- renfort / complément ;
- retour au calme ;
- séries / reps / rounds / temps / distance selon le sport ;
- repos, RPE, tempo ;
- charge suggérée uniquement lorsqu’un historique le permet ;
- remplacement d’un exercice ;
- adaptation d’une séance ;
- mode séance en direct ;
- partage, impression/PDF.

## Bibliothèque sportive
- 423 variantes uniques ;
- 15 univers d’entraînement ;
- 161 mouvements maîtres.
