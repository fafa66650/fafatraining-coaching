# FAFATRAINING Coach Studio — V95

Version UX/programmation/social construite à partir du socle précédent.

## Points clés
- 595 mouvements, classement explicite par zone + muscle, variantes intégrées.
- 184 programmes prêts à utiliser, réellement répartis selon les univers et objectifs.
- Trois niveaux de matériel clairs : sans matériel, matériel léger transportable, matériel de salle.
- Accueil simplifié, suppression des doublons, univers homogènes et palette d’accents.
- Timer à validation explicite avec presets et steppers.
- Studio Social : export direct d’un programme prêt en carrousel Instagram, Story/TikTok, couverture Reel et fiche adhérent.
- Responsive / safe areas / navigation retour / micro-interactions.

Déploiement GitHub Pages : envoyer le contenu du ZIP à la racine du dépôt. `index.html` doit rester à la racine.
