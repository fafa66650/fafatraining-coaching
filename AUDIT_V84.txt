FAFATRAINING V84 — AUDIT COMPLET

CAUSE DE L’ÉCRAN NOIR TROUVÉE ET CORRIGÉE
- La V83 dépendait de modules JavaScript ES et de chargements JSON par fetch au démarrage.
- En ouverture directe depuis le fichier téléchargé, les règles de sécurité des navigateurs peuvent bloquer ces modules/fetch et laisser l’écran vide.
- La V84 utilise maintenant un bundle autonome classique avec les données embarquées : aucun fetch JSON n’est nécessaire pour afficher l’application.
- Le service worker est désactivé en ouverture locale file://.
- Si une erreur JavaScript survient malgré tout, un message visible s’affiche à la place d’un écran noir.
