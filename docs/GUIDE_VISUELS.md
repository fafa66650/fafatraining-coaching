# Guide visuels

Chaque exercice a deux visuels possibles :
1. Photo réaliste : `assets/photos/...`
2. Avatar en action : `assets/avatar/...`

Consulte `VISUELS_A_CREER.csv`.

Important :
- garde les noms exacts ;
- format JPG pour les photos ;
- format PNG pour les avatars avec fond transparent si possible ;
- un mouvement = une image claire.
