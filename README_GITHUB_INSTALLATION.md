# FAFATRAINING V50 — Version GitHub installable

Cette version est prête pour GitHub Pages et installable sur iPhone comme une vraie application.

## Installation GitHub Pages

1. Va sur ton dépôt GitHub : `fafa66650/fafatraining`
2. Supprime ou remplace les anciens fichiers.
3. Glisse tout le contenu de ce dossier à la racine du dépôt :
   - `index.html`
   - `style.css`
   - `app.js`
   - `manifest.json`
   - `service-worker.js`
   - `.nojekyll`
   - dossiers `assets/` et `data/`
4. Commit : `V50 GitHub installable`
5. Va dans Settings > Pages
6. Source : `Deploy from a branch`
7. Branch : `main` / root
8. Ouvre : `https://fafa66650.github.io/fafatraining/`

## Installer sur iPhone

1. Ouvre le lien dans Safari.
2. Appuie sur Partager.
3. Choisis `Sur l’écran d’accueil`.
4. Valide.
