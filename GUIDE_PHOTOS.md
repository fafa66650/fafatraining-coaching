# Guide photos — FAFATRAINING COACHING

Objectif : obtenir le rendu type Enrx avec de vraies photos propres.

## Où mettre les photos
Place les fichiers dans :

assets/photos/exercises/

Les dossiers sont déjà créés par catégorie.

## Liste exacte des noms
Utilise le fichier :

PHOTOS_A_AJOUTER.csv

Chaque ligne donne :
- l’exercice
- le dossier
- le nom exact attendu
- le chemin complet

## Format conseillé
- JPG
- 640x420 minimum
- 1280x840 idéal
- fond sombre / salle
- mouvement visible
- matériel visible
- une photo différente par exercice

## Important
Si une photo manque, l’application affiche “Photo à ajouter” au lieu de mettre ton logo.
