# FAFATRAINING V50 — Assemblage des parties

Tu dois récupérer les 3 ZIP :
- V50_PART_1_CORE.zip
- V50_PART_2_AVATARS.zip
- V50_PART_3_EXTRAS.zip

## Assemblage sur Mac/PC
1. Dézippe les 3 fichiers.
2. Ouvre chaque dossier.
3. Copie tout le contenu des PART 2 et PART 3 dans le dossier PART 1.
4. Tu dois obtenir :
   - index.html
   - style.css
   - app.js
   - manifest.json
   - service-worker.js
   - data/
   - assets/
5. Renomme le dossier final : FAFATRAINING_V50_COMPLETE
6. Tu peux l’envoyer sur GitHub.

## Important
Quand l’ordinateur demande “fusionner les dossiers”, accepte.
Ne remplace pas le dossier complet, fusionne les contenus.
