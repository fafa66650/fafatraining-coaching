CAUSE RÉELLE DE L’ÉCRAN NOIR V84
- Le bundle V84 contenait encore `export async function importState(...)` alors qu’il était chargé comme script JavaScript classique.
- Un navigateur classique arrête alors l’analyse du fichier avec « Unexpected token export » avant même `init()` : résultat = page noire.
- Le contrôle précédent avec `node --check` n’était pas suffisant pour reproduire exactement ce mode de chargement navigateur.

CORRECTIONS STRUCTURELLES V85
- Reconstruction propre avec un nouveau fichier runtime `src/fafatraining-v85.js`.
- Aucun `import` ni `export` JavaScript.
- Aucun chargement JSON par fetch au démarrage : les données sont embarquées.
- Nouveau CSS versionné pour éviter les anciens caches.
- Désinscription automatique des anciens Service Workers et suppression des anciens caches.
- `service-worker.js` conservé uniquement comme worker d’auto-destruction pour neutraliser une ancienne inscription persistante.
- Watchdog visible : même si le moteur casse, l’utilisateur ne reste plus devant un écran noir silencieux.
- Boutons de partage natif + E-mail + SMS + copie de secours.
